# Question-and-answering
<p>This is where we creating a chatBot similar to to the chatGPT, but this chatBot contain to models to respond you questions.
That is HuggingFace model and Gemini model.</p>

# How to run
- First you have to clone this repository , for that type.
  ```bash
  git clone https://github.com/balamahi077/Question-and-answering.git
  ```
- after that create new virtual envirement, type
  ```bash
  python -m venv venv
  ```
- before installing packages activate the virtual envirement, type
  ```bash
  cd venv
  Scripts\activate
  ```
- install required packages
  ```bash
  pip install requirements.txt
  ```
- Now you run this project...
```bash
streamlit run main.py
```
